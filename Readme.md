# ✈️ Aviation Analytics Dashboard Using Excel

## 📌 Project Overview

The **Aviation Analytics Dashboard** is a data analytics project developed using Microsoft Excel to analyze flight data and identify useful insights into aviation operations.

The project uses PivotTables, PivotCharts, KPI cards, and interactive slicers to summarize flight information, analyze airline performance, and explore flight-related trends.

Due to the large size of the dataset and project files, the complete files are available through Google Drive.

## 🎯 Project Objectives

* Analyze aviation and flight-related data.
* Identify the number of flights and unique airlines.
* Analyze flight delays and cancellations where data is available.
* Compare flight activity across airlines and airports.
* Create interactive visualizations for exploring flight trends.
* Present key insights through an Excel dashboard.

## 🛠️ Tools and Technologies

* **Microsoft Excel** — Data analysis and dashboard development
* **PivotTables** — Data summarization and aggregation
* **PivotCharts** — Visual representation of flight data
* **Slicers and Timelines** — Interactive filtering
* **Excel Formulas** — KPI calculations and data analysis

## 📊 Dashboard Features

* **KPI Cards:** Summarize important flight statistics.
* **Airline Analysis:** Compare flight volumes across airlines.
* **Flight Delay Analysis:** Examine departure delays and airline performance.
* **Airport Analysis:** Identify airports with high flight activity.
* **Monthly Trends:** Explore changes in flight activity over time.
* **Cancellation Analysis:** Analyze cancelled flights if cancellation data is available.
* **Interactive Filters:** Filter dashboard results using slicers and timelines.

*The final dashboard includes metrics and visualizations supported by the available dataset.*

## 🚀 How to Use the Project

1. Open the Google Drive link provided above.
2. Download the Excel dashboard workbook.
3. Open the workbook using Microsoft Excel.
4. Navigate to the `Dashboard` worksheet.
5. Explore the KPI cards and charts.
6. Use the available slicers to filter the data.
7. If necessary, use **Data → Refresh All** to refresh PivotTables and charts.

If Excel displays a security warning, enable external content only when you trust its source. The dashboard should not require enabling macros unless macros have actually been included.
